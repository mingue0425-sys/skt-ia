Linux ARM64에서 실제 공급자 자료로 7개 모델을 학습하고 고정된 미사용 test 구간을 평가했다.
**NOT_STRICT_PIT / 선정된 5종목의 제한된 개인 비상업 연구**다.
학습 모델은 이번 test의 기준선보다 개선되지 않았다. 집계 수치는
[결과 JSON](real_data_baseline.json)에, 원본·DB·개별 예측·모델은 gitignored
`data/real_data_baseline/`에 보관한다. 기존 Stage2~5.5 자료·미커밋 변경은 유지했다.

## 1. 출처·기간·가격 의미

EODHD의 공식 무계정 demo API에서 2021-07-01~2026-10-02 일별 자료를 수신했다.
AAPL/MSFT/AMZN/TSLA/MCD를 평가 전에 고정했고, 5종목 모두 접근에 성공해 종목·기간을 줄이지 않았다.
종목당 1,320행, 총 **6,600 OHLCV행·분할 2건·배당 63건**이다.
실제 수신 UTC 범위는 JSON의 `collection_received_at_range`에 기록했다.

| 종목 | 공급자 General의 ISIN | 일별 행 | 분할 | 배당 |
|---|---|---:|---:|---:|
| AAPL | US0378331005 | 1,320 | 0 | 21 |
| MSFT | US5949181045 | 1,320 | 0 | 21 |
| AMZN | US0231351067 | 1,320 | 1 | 0 |

General의 Code/Common Stock/USD/ISIN을 대조했다. 이는 현재 공급자 식별이며 역사적 코드·share-class master의 완전성 검증은 아니다.
기존 후보의 IBM raw에는 기업행동이 없고 Yahoo의 자동 수집·학습 조건은 미확정이었다.
추가 확인은 Nasdaq WIKI와 EODHD 두 곳으로 제한했다. WIKI는 실제 요청에서 키 필요 HTTP 403으로 끝났고 우회하지 않았다.

[일별 명세](https://eodhd.com/financial-apis/api-for-historical-data-and-volumes)의 OHLC는 원가격,
`adjusted_close`는 분할·배당 수정종가, volume은 현재 버전의 분할 조정 주식 수다.
수정종가는 원본에 보존하되 이번 특징·정답에 사용하지 않았다. 거래대금 특징은 계산하지 않았다.
공급자 [약관](https://eodhd.com/financial-apis/terms-conditions)은 가격을 indicative로 설명하며 거래소 직접 feed·공식 시가 경매 가격을 보증하지 않는다.
이번 결과는 이 공급자 일별 시가 계열에 대한 예측 평가다.

[기업행동 명세](https://eodhd.com/financial-apis/api-splits-dividends)에 따라 split은 new/old,
배당은 `unadjustedValue`·ex-date·payment-date·currency를 별도 보존했다.
AMZN의 2022-06-06 20:1, TSLA의 2022-08-25 3:1 분할을 확인했다.
누락된 기준 달력 세션·중복·파싱/가격 구조 오류는 0건이다. 원가격 분할 경계의 급락 경고 2건은 보존했다.
빈 분할/배당 배열도 원본으로 보관하며, 이를 독립적인 무사건 증명으로 승격하지 않았다.

## 2. 연구 가정과 이용 조건

사용자가 **개인 비상업 연구, 별도 계약·키 없음**을 확인했다.
약관의 개인 목적 저장·변형·분석 허용과 공식 demo의 평가 용도를 근거로 이번 로컬 일회성 통계 모델 평가를 수행했다.
모델 fit을 개인 분석 범위로 해석한 것이며 별도의 명시적 ML·영구 보관·모델 배포 허가를 확인했다는 뜻은 아니다.
원본·정규화·행 단위 자료·모델을 공개 저장소에 추가하거나 커밋·푸시하지 않았다.

현재 제공되는 과거 버전만 사용한다. 당시 최초 공개·수신 버전은 미확인이다.
공개 시각의 null은 유지하고, `research_assumed`에서만 기준 달력 장 마감+15분 가용성을 가정했다.
특징 결정은 마감+60분이다. 알려진 정정 시각이 있으면 연구 가정보다 늦은 정정 시각을 적용한다.
현재 확인한 학습 권한 시각은 실제 실행 기준으로 검사하며 과거 training cutoff로 소급 기록하지 않는다.

기업행동은 공급자의 현재 분할·배당 응답이 해당 구간을 완전히 포함한다고 가정한다.
coverage는 `research_assumed_complete`로 표시하며 strict/observed 계산의 `verified_complete`와 구별한다.
과거 정지·특수 분배·합병 사건의 독립적 완전성, 실제 세션 범위·시가 경매 일치도는 미확인이다.
달력은 고정한 `exchange_calendars` XNYS 기준이며 역사적 공지 버전은 검증하지 않았다.
현재 선정된 존속 종목의 생존·선정 편향이 있다. 과거 전체 시장을 대표하지 않는다.
실제 strict 선택 결과는 **0개**이며 연구 실행을 strict PASS로 바꾸지 않았다.

## 3. 표본·시간 분할·정답

일별 원본을 lookback과 진입/종료 가격에 사용하고, 첫 소규모 실행의 결정 표본은 평가 전에 **월요일 세션만**으로 고정했다.
종목당 233개, 총 **1,165개의 5일 정답**이 ready다. 품질 이유로 임의 삭제한 가격 행은 없다.
기존 builder가 함께 만든 1/20일 정답은 이번 고정 학습 dataset에 포함하지 않았다.

정답은 다음 거래일 시가에 1주 진입해 **진입 세션 e+5의 시가**까지 보유한 가격수익률이다.
분할은 보유 수량에 한 번 반영하고 배당 현금은 가격수익률에서 제외한다.
`cash_total_return`은 별도 계산 상태로 보존하며 이번 학습 target은 `price_return`이다.
상승 여부는 이 가격수익률 > 0이며 0은 비상승이다. 종가 체결·가공 시가는 사용하지 않았다.

| 구간 | 사전 고정 날짜 범위 | 실제 포함 결정 날짜 | 표본 | 날짜 수 |
|---|---|---|---:|---:|
| train | 2021-10-01~2024-09-30 | 2021-10-04~2024-09-16 | 680 | 136 |
| validation | 2024-10-01~2025-09-30 | 2024-10-07~2025-09-22 | 235 | 47 |
| test | 2025-10-01~2026-09-25 | 2025-10-06~2026-09-21 | 235 | 47 |

논리적 training_asof는 2024-10-01 00:00 UTC다. 실제 모델 계산 시각은 현재 실행 시각으로 별도 저장했다.
test 진입은 2025-10-07부터, 마지막 종료는 2026-09-29 시가다.
train 10개·validation 5개, 총 **15개**를 성숙 시각/정답 구간 경계 검사로 제외했다.
이유별 count는 학습 시각 부적격 10·validation 침범 5·test 침범 5이며 일부 이유가 같은 표본에 중복된다.
평가 단계 제외는 0개다. 모든 모델이 동일한 test 235개, 날짜당 5종목을 사용했다.

## 4. 고정 모델·전처리

특징은 기존 구현의 `close_price_change_5`, `close_to_ma_20`,
`realized_log_price_change_volatility_20`, `intraday_high_low_ratio`, `volume_to_prior20_mean` 5개다.
원가격 변화 특징은 분할 경계를 포함하는 비경제적 가격 변화로 유지했다.
결측 처리·상수 열 판단은 train에서만 적합하고, Ridge/Logistic의 스케일링도 train에서만 적합했다.

회귀 기준선은 0과 train 평균, 분류 기준선은 alpha=1의 train 상승 빈도다.
Ridge alpha=1/solver=svd, Logistic C=1/solver=lbfgs/max_iter=300/tol=1e-8,
작은 트리는 max_depth=3/min_samples_leaf=8, seed=20261003이다.
분류 정확도 threshold는 0.5다. 하나의 explicit fold를 사용했고 validation/test로 설정을 선택하거나 변경하지 않았다.

## 5. 고정 test 지표

수익률은 소수 단위다. 예를 들어 MAE 0.034102는 약 3.4102%p다. MSE는 소수 수익률의 제곱 단위다.

| 회귀 | MAE | MSE | 방향 정확도 | 날짜별 Rank IC 평균 |
|---|---:|---:|---:|---:|
| 0 기준선 | 0.034102 | 0.002190427 | 51.49% | 상수 예측으로 미정의 |
| train 평균 | 0.034323 | 0.002203240 | 48.51% | 상수 예측으로 미정의 |
| Ridge | 0.034420 | 0.002272140 | 49.36% | 0.053191 |
| 작은 트리 | 0.036592 | 0.002594153 | 47.66% | 0.018081 |

| 분류 | Brier score | 방향 정확도 |
|---|---:|---:|
| train 빈도 | 0.251865 | 48.51% |
| Logistic | 0.252964 | 48.51% |
| 작은 트리 | 0.261079 | 48.51% |

Ridge/트리의 MAE·MSE와 Logistic/트리의 Brier score 모두 해당 기준선보다 나빴다.
Rank IC는 Ridge 47일·트리 16일에서 정의된다. 위 각자 평균의 날짜 집합은 다르다.
**공통 16일**에서 비교하면 Ridge 0.031250, 트리 0.018081이다. 상수 기준선의 IC는 미정의다.
소수 종목의 기술 통계이며 유의성 증거가 아니다. 날짜 수와 공통 비교는 JSON에 기록한다.
표본은 47개 test 날짜에 걸친 5종목이며 종목 간 상관과 일부 휴일 구간의 정답 중첩이 있다.
독립 표본 235개나 시장 전체의 검증으로 해석하지 않는다.

## 6. 시뮬레이션·필수 확인

시뮬레이션은 **NOT_RUN**이다. indicative 일별 시가와 가정된 거래 상태/기업행동 완전성으로는
Stage4의 체결·기업행동 입력 계약을 충족했다고 확인할 수 없다. 비용 수익률·Sharpe 결과는 생성하지 않았다.
새 시뮬레이터나 체결 자료 대체값을 만들지 않았다.

관련 기존 PIT·미래 특징/정답 차단·train 전용 전처리·권한·snapshot 손상 검사를 실행했다.
새 연구 경로의 cutoff/미래 정정 시각과 assumed coverage의 strict 차단을 확인했다.
실제 7개 모델의 JSON 저장→재로드→예측을 수행하고 같은 입력·설정의 재학습 예측을 rtol=atol=1e-12로 비교했다.
상세 상태는 JSON의 `reproducibility`에 남긴다.
실제 실행에서 확인한 중복 해시 병목은 snapshot 안에서 같은 파일을 한 번씩 확인하도록 최소 수정했다.
행별 버전·참조·hash 검사는 유지하고 파일 확인을 실행 간 캐시로 생략하지 않는다.
