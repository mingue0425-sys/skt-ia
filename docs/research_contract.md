# 1단계 연구 계약

작성일: 2026-10-02. 미국 상장 보통주, 향후 당시 유동성 기준 약 100개 증권,
10–15년 범위를 목표로 **접근 가능성**을 조사한다. 샘플은 수집기 검증용이며
현재 생존 종목 목록은 과거 전체 투자 종목군을 대체하지 못한다.

장기 가정: 각 거래일 정규장 마감 60분 후 정보 마감, 다음 거래일 시가 진입,
진입 후 1·5·20거래일(주력 5일), 매수·현금만 허용. 조기 폐장일에는 실제
정규장 마감에 60분을 더한다. America/New_York와 UTC를 구분하고 DST를 반영한다.
이 문서는 거래 규칙 가정이며 이번 단계에 거래 시스템을 구현하지 않는다.

범위: 요구 필드 정의, 공식 문서 조사, 5–10개 증권의 제한된 실제 샘플,
원본 보관·manifest·정규화·품질 검사·재현 명령·2단계 조건.
모델 학습, 수익성/예측력 주장, 자동매매, 대시보드, 전체 PIT DB는 제외한다.

상태 표기는 `실제 다운로드와 검증 완료`, `공식 문서에서 확인했지만 미검증`,
`접근 제한으로 확인 불가`, `제공하지 않거나 요구사항 미충족`의 네 가지다.
상태는 제공처 전체가 아니라 데이터/필드/권한 단위로 판정한다.

가격 날짜는 관측 거래일이며 공개 시각이 아니다. 최초 공표 시각을 모르면
null로 둔다. fetched_at은 이번 수신 시각이며 역사적 당시 수신 시각이 아니다.
현재 수정된 과거 응답을 버전 보관하는 기능은 과거 최초 공개 버전의 복원이 아니다.
현재 조회한 상장 상태·업종·조정계수를 과거의 알려진 정보로 사용하지 않는다.

작은 순차 다운로드, 표준 Python HTTP/JSON/CSV, 파일 기반 보관과 검증용 달력
라이브러리만 사용한다. Linux ARM64에서 실행하되 macOS/Apple Silicon을 지원하는
Python 패키지 구조를 사용한다. 외부 키나 계약은 기존 권한이 있을 때만 이용하고
계정 생성·결제·계약 동의를 자동 수행하지 않는다. 합성 fixture는 tests 전용이다.
